# Privacy Policy for Embershot

**Effective Date:** October 31, 2026

Embershot ("the Extension") is a local-first browser screenshot and optical inspection utility. We do not operate analytics trackers, ad networks, or cloud image-hosting servers.

## 1. Data Collection & Local Storage

By default, **Embershot collects, transmits, and shares zero personal or browsing data.** All image and video processing, including viewport capture, full-page stitching, interactive section/element cropping, live in-page CSS/DOM previewing, local screen/tab/microphone video recording, manual image import, Studio cropping, vector annotation, background chroma removal/replacement, DOM text replacement, PII redaction, visual comparison, framing, SVG minification, and 9-format encoding/conversion (`PNG`, `WEBP`, `JPEG`, `AVIF`, `BMP`, `SVG`, `GIF`, `ICO`, `PDF`, plus local `MP4`/`WEBM` video clips), is performed locally inside your browser using native Web and Extension APIs.

Data stored strictly on your device via **IndexedDB** (`embershot_optical_vault_v1`), `browser.storage.local`, and `browser.storage.sync` includes:

- **Extension Preferences (`embershot_settings`, `embershot_locale_v1`, `embershot_locale_sync_v1`, `embershot_storage_quota_v1`, `embershot_telemetry_stats`, plus synchronous `localStorage` first-paint cache keys `embershot_boot_settings_v1`, `embershot_boot_theme_v1`, `embershot_boot_mode_v1`, `embershot_boot_palette_v1`, `embershot_boot_font_v1`, `embershot_boot_corner_v1`, `embershot_boot_btngroup_v1`, `embershot_boot_custom_colors_v1`, `embershot_boot_google_font_url_v1`, `embershot_has_booted_popup_v1`, `embershot_has_booted_studio_v1`):** Appearance theme, interface language (`en`, `fr`, `ar`, `es`, `de`, `ja`, `pt`, `zh`, `ko`), cycling capture delay (`0s`, `1s`, `2s`, `3s`, `5s`, `10s`), fixed-element locking, output format (`png`, `webp`, `jpeg`, `avif`, `bmp`, `svg`, `gif`, `ico`, `pdf`), filename prefix, default Studio workflow preset, local storage quota ceiling (`1 GB` default), local capture counter, and optional opt-in local capture/export performance timings (`perfTelemetryEnabled`, disabled by default).
- **Studio Productivity, Integrations & Layout State (`embershot_studio_shortcuts_v1`, `embershot_studio_tour_seen_v1`, `embershot_color_palette_v1`, `embershot_color_history_v1`, `embershot_studio_color_history_v1`, `embershot_workflow_presets_v1`, `embershot_buffer_more_filters_open_v1`, `embershot_studio_inspector_ui_v1`, `embershot_studio_bottom_hud_hidden_v1`, `embershot_pending_studio_nav_v1`, `embershot_integrations_v1`, plus ephemeral session-only `embershot_armed_flight_tabs_v1`):** Your customized Studio keyboard shortcut bindings, custom color palette swatches, the last 10 colors picked with the page color picker and with the Studio eyedropper (hex value, time, and source page title/URL), custom presentation workflow presets, optional user-configured issue-tracker targets and Bring-Your-Own Slack/Discord webhook or S3/Cloudflare R2 credentials (`embershot_integrations_v1`, stored strictly in local device storage and excluded from settings backups and browser sync), ephemeral tab IDs armed for the opt-in session Flight Recorder (`browser.storage.session`, cleared automatically when the tab or browser closes), Optical Buffer filter disclosure state, Right Inspector rail/section state, bottom canvas HUD toggle state, pending Studio tab navigation state, and whether the interactive Studio onboarding tour has been completed.
- **Embershot Pro License, Daily Allowance & Trial State (`embershot_pro_license_v1`, `embershot_daily_pro_usage_v1`, `embershot_trial_ledger_v1`):** Your optional Embershot Pro license key, daily local Free-tier Pro allowance counters (`3/day` Pro exports and `1/day` batch conversions, reset at local midnight), 7-day Pro trial timestamps, anonymous browser device ID (`embershot_device_id_v1`), and activation status synced via `browser.storage.sync` so your Pro unlock and trial state persist across your signed-in browsers.
- **Optical Buffer History, IndexedDB Binary Vault, Encrypted Private Vault, Per-Capture Edits & Issue Context (`embershot_optical_vault_v1`, `embershot_history`, `embershot_capture_edit_states_v1`, `embershot_private_vault_meta_v1`, `embershot_private_vault_items_v1`):** Up to 20 recent captures and 5 protected favorites on the Free tier (or unlimited capture history up to your configured local storage quota and up to 25 protected favorites on the Embershot Pro tier) stored as binary Blobs in local IndexedDB (`embershot_optical_vault_v1`), optional client-side WebCrypto `PBKDF2` + `AES-256-GCM` encrypted vault items (`embershot_private_vault_meta_v1`, `embershot_private_vault_items_v1`), paired with lightweight metadata in `browser.storage.local` including favorite flags (`isFavorite`), local QA issue context (`severity`, `status`, `tags`, `notes`), local DOM PII bounding boxes (`piiRegions`) for 1-click Auto-Shield redaction, passive technology stack telemetry (`techStackDetails`), extracted page links (`pageLinks`), passive `document.cookie` / `localStorage` / `sessionStorage` snapshots (`cookiesSnapshot`, masked by default in the UI and masked in exported Evidence Bundles), and non-destructive Studio edit states so you can inspect, compare, crop, annotate, remove backgrounds, reorder, copy, convert, or re-export screenshots. Non-favorited oldest captures are automatically evicted when slot or storage quota limits are reached, and non-favorites or all captures can be purged manually at any time.
- **Exported File & Evidence Bundle Metadata Transparency:** Exported `PNG`, `WEBP`, `JPEG`, `AVIF`, `BMP`, `SVG`, `GIF`, `ICO`, and `PDF` files contain pure rendered image data without hidden EXIF/XMP tracking metadata. Source URL and capture timestamps are drawn onto an exported image **only** if you explicitly enable the **Window Header Bar** or **QA Telemetry Stamp** in the Studio Presentation Chassis, and optional sections (tech stack, DOM faults, page links, and opt-in masked cookie/storage summaries) are included in exported **Markdown / HTML / JSON Evidence Bundles** **only** when their checkboxes are checked in the Evidence Export modal.

## 2. Optional User-Initiated Network Requests

Embershot makes network requests to its own services **only** when you explicitly activate an Embershot Pro license key or start the 7-day Pro trial. All other external requests happen **only** from explicit user-initiated Studio tools directly from your browser to the target URLs, never through Embershot servers:

- **On-Demand Link Health Verification (`Verify Links`) & Deep Tech Stack Scan (`Deep Scan Site`):** Only when you click **Verify Links** in the Page Links inspector or **Deep Scan Site** in the Tech Stack inspector does the background service worker send stateless (`credentials: "omit"`) HTTP requests directly to the captured page's asset or link URLs to inspect response status codes and public framework signatures.
- **Blocked GIF Hydration:** When you capture an animated GIF, Embershot downloads that image directly from the site hosting it (the same request your browser already made to display it); nothing is sent to Embershot or any other third party.
- **Embershot Pro License Activation & 7-Day Trial Verification:**
  - When you activate an Embershot Pro license key or start the 7-day Pro trial, the extension communicates with our license verification endpoint (`https://license.embershot.workers.dev`) using your license key (if applicable) and an anonymous browser `deviceId` (plus a one-way SHA-256 fingerprint for trial deduplication) to confirm your membership or trial eligibility.
- **Optional User-Configured Google Fonts & Bring-Your-Own (BYO) Destinations:**
  - All 4 built-in UI font families are bundled offline. Only if you explicitly paste and import a custom Google Font URL in Settings does your browser load that stylesheet and font from `fonts.googleapis.com` / `fonts.gstatic.com`.
  - Optional **Issue-Tracker Handoff** opens your chosen GitHub, GitLab, Linear, or Jira new-issue URL directly in a browser tab while copying the PNG to your local clipboard. Optional **Slack/Discord Webhooks** and **S3-Compatible / Cloudflare R2** uploads in **Settings → Integrations** transmit your exported capture directly from your browser to your own configured endpoint only when you click push/upload, never through Embershot servers.

## 3. Permissions Used

| Permission                                           | Purpose                                                                                                                                                                                                                                                                                                                                                           |
| :--------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `activeTab`                                          | Grants temporary, user-initiated access to the currently active tab when you trigger a capture via the toolbar popup, keyboard shortcut, or context menu.                                                                                                                                                                                                         |
| `scripting`                                          | Injects the on-demand optical region/element pickers, scrolls pages for full-page and unclipped element stitching, suppresses duplicate sticky headers, and displays the post-capture toast strictly on the active tab.                                                                                                                                           |
| `storage` & `unlimitedStorage`                       | Saves user settings, storage quota preferences, customized Studio shortcuts, custom color swatches, synced Embershot Pro license/trial state, and high-resolution capture blobs in local storage and IndexedDB.                                                                                                                                                   |
| `downloads`                                          | Saves exported and converted files (`PNG`, `WEBP`, `JPEG`, `AVIF`, `BMP`, `SVG`, `GIF`, `ICO`, `PDF`, `HTML`, `JSON`, `CSV`, `MD`, `TXT`, `SH`) to your local Downloads folder.                                                                                                                                                                                |
| `clipboardWrite`                                     | Copies captured/annotated PNG images, sampled pixel colors (`HEX`, `RGB`, `HSL`, `ARGB`), source URLs, link/cookie export snippets, Markdown evidence reports, or extracted DOM CSS/JSON specifications to your clipboard when requested.                                                                                                                          |
| `contextMenus`                                       | Adds right-click browser context menu shortcuts for capturing the visible viewport, full page, selected region, DOM element, or opening the Optical Studio.                                                                                                                                                                                                       |
| `declarativeNetRequestWithHostAccess`                | Only acts on hosts you have granted below. While fetching a blocked GIF, Embershot adds a temporary session rule that sends the page's origin as the `Referer` header (what the page itself sends) for that one image URL, for extension requests only, and removes the rule as soon as the fetch finishes.                                                       |
| Optional `cookies` permission                        | Not granted at install. Only requested when you click **Unlock Full Cookies** in Studio's Cookies & Web Storage Inspector or enable **Cookies API Access** in **Studio Settings → Permissions & Access**, allowing `browser.cookies.getAll()` to inspect `HttpOnly`, `Secure`, `SameSite`, and expiration metadata strictly on-device. Can be revoked at any time. |
| Optional host access (`*://*/*`, per-site or universal toggle) | Not granted at install. Requested on-demand per host when fetching blocked GIFs, running **Deep Scan Site**, unlocking site cookies, or manually adding a site in **Studio Settings → Permissions & Access**. You can also toggle universal `*://*/*` access or inspect and revoke individual granted sites (or revoke all at once) from the Permissions & Access tab at any time. |
| Existing `activeTab` capture APIs                    | When **Record GIFs when a site blocks downloads** is enabled and direct GIF hydration fails, Embershot samples the visible active tab locally at a bounded interval until one animation loop is detected. Samples are cropped and encoded into a displayed-resolution GIF in local IndexedDB. No extra recording permission is requested and nothing is uploaded. Optional interactive **Region GIF Recording** likewise samples only your selected viewport region locally in memory via `activeTab` and encodes the GIF on-device with zero external transmission. |

## 4. Third-Party Sharing & Data Sales

We do not collect, sell, rent, or transfer user browsing or screenshot data to any third parties, data brokers, or analytics providers.
